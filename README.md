# Happy Birthday Linh — LYN A.I

Trang web chúc mừng sinh nhật tuổi 19 của Linh (6/11/2007 – 6/11/2026), do LYN A.I dẫn chuyện.

- Thiết kế web & ý tưởng: Vinh Lê
- Platform: LYN A.I

## Cách xem

Mở `index.html` bằng trình duyệt, rồi bấm hoặc chạm vào màn hình để sang từng câu.

## Cấu trúc

```
index.html            khung trang và lời thoại (mỗi .text-line là một lần bấm)
css/base.css          giao diện chính
css/overrides.css     các bản tinh chỉnh theo từng cảnh (giữ nguyên thứ tự)
css/outro.css         dòng thoại, nút Đồng ý, outro "con đường giấc mơ" và credit
js/main.js            luồng chuyển cảnh, nhạc, mắt LYN và phần kết
js/*.js               hiệu ứng phụ (trời sao, hoa, hạt sáng, tối ưu mobile)
assets/audio/         nhạc nền
assets/video/         video cảnh nụ cười
assets/images/        ảnh nền các cảnh
assets/images/memories/  16 ảnh cho đoạn hồi tưởng
```
